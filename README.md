# IGMI

In-Game-Mod-Installer for Minecraft.

Install and manage Minecraft mods directly from inside the game.

## Features

- In-game mod installation
- Mod discovery
- Mod downloading
- Mod management
- Mod updates
- Dependency handling
- Minecraft-version compatibility
- Mod-loader compatibility
- Safe installation workflow

## Supported Platforms

- Fabric
- More loaders may be supported in future versions

## Supported Minecraft Versions

IGMI is designed to support multiple Minecraft versions.
Check the releases page for the currently supported versions.

## Installation

1. Download the correct IGMI version.
2. Put the `.jar` file into your `mods` folder.
3. Launch Minecraft with the required mod loader.
4. Open IGMI in-game.

## Requirements

- Minecraft
- Compatible mod loader
- Required dependencies, if listed

## Issues

If you encounter a bug, open an issue with:
- Minecraft version
- IGMI version
- Mod loader
- Crash log
- Steps to reproduce
